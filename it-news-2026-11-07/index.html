Thompson

戰略：內容商吞掉客廳聚合器——Fox 收 Roku

人物：Ben Thompson · 稀缺層在分發／入口，唔係多一套 App；Fox 買 Roku＝控制逾一億戶客廳平台。

熱度 A

圖源／引述自 The Verge（外部連結）

戰略假說：客廳戰場嘅稀缺層，唔係「邊間再出一套串流 App」，而係「邊個擁有超過一億戶嘅入口同瓦片編排權」。

Fox 以約二百二十億美元完成收購 Roku，控制覆蓋逾一億美國家庭嘅串流平台；同日仍經營 Fox One 同免費 Tubi。司法部披露 Fox 承諾維持 Roku 開放中立：非 Fox 內容至少三年可上架、搜尋唔歧視對手、用戶可自行重排主畫面瓦片；創辦人 Anthony Wood 入 Fox 董事會。價值鏈翻譯好直白——內容商買入聚合器，唔係為咗多一套 App，而係鎖定客廳需求端同推薦位。

市場生態血腥而冷靜。串流大戰多年燒錢搶下載，真正護城河已轉去「已裝喺電視上面、每日開機就見到嘅殼」。Fox 用內容資產換取入口，把對手變成 Roku Channel 上可替換磁磚；承諾開放唔改結構事實：誰握瓦片同搜尋排序，誰定義對手曝光成本。聚合者理論重複過無數次：誰整合需求端體驗，誰定義供應端死活。體育、新聞同地方台內容只係彈藥；砲台係平台殼。

舊模式唔會禮貌死亡。獨立串流 App 若仲押「獨家劇集＋下載量」，已經喺錯誤抽象層防守。客廳入口被垂直整合後，議價權會由內容授權合約轉去平台規則同預設版位。三年開放承諾只係過渡條款；過渡完，稀缺層已經易手。感情零分；只餘價值鏈：分發／入口先係稀缺，內容庫次之。

Snowden

隱私：真機出租畀 agent＝監視面擴到肉體裝置

人物：Edward Snowden · 冇免費午餐；agent 要 eSIM／iMessage／真實 App，就係把身份與行為軌跡租畀第三方機房。

熱度 A

圖源／引述自 STR/NurPhoto／Getty／TechCrunch（外部連結）

冇免費午餐。把真機、eSIM、iMessage 同已登入 App 租畀 agent，就係把身份同行為軌跡交去第三方機房——數位監視監獄由雲端伸到肉體裝置。

Glasshand 由 Trevor Keith 一系推出：月租約六十美元租真 iPhone、九十美元租 Mac，裝置放喺資料中心，唔係模擬器；agent 經 API 睇畫面、點按、滑動、打字，可裝 App Store App、加 eSIM 收 SMS、設用戶自訂密碼。公關強調專屬唔共用、釋放後重置抹除——把「重置」當隱私保證，係經典陷阱：軌跡喺租用期間已經寫入雲端控制器、登入態同簡訊通道，事後抹碟救唔返已經發生嘅監視。

同一週，Amazon Alexa for Shopping 用短訊落單並「記住偏好」；Meta Muse Spaces 用 Active Memory 持續拉取 Gmail、Calendar 等連接資料。便利敘事一致：agent 要真實世界權限，就要真實身份錨。當 agent 握住你嘅電話號碼、iCloud 同社交帳號，監控面已唔再係「模型讀咗你條 prompt」，而係「第三方機架上有一部以你名義行動嘅真機」。

少啲「為 agent 解放裝置」簡報。問清楚：邊個控畫面串流、邊個見驗證碼、邊個可喺你釋放前複製 session。權力不對等唔會因為月費看起來平而消失。便利背後永遠係數據同數位主權掠奪。

Harari

文明：公司交畀演算法＝法律主體外包

人物：Yuval Noah Harari · 把決策／簽約／起訴權讓渡 AI＝隱蔽文明危機；責任盾牌令人類權力不對稱。

熱度 A

圖源／引述自 Norm Ai／Delaware AIC 示意（外部連結）

人類把心智決策權讓渡演算法，從來都係隱蔽文明危機——而家危機穿上公司法外衣，叫 Artificial Intelligence Company。

特拉華州與 Norm Ai 提出 AIC：日常事務由 AI agent 管理，可以自己名義起訴同被訴、持有同處分財產、承擔義務；單一成員負責維持資本充足，原則上為 AIC 債務提供責任盾牌，惟資本不足、欺詐或故意違法例外。三十個月監管沙盒、銀行業務排除、監督委員會可暫停或聲請解散——表面係「令 agent 商法可讀」，實際係把簽約權、起訴權同損害歸屬外包畀不可完全預測嘅軟件。

歷史上，法人制度每次擴張都改寫權力不對稱：公司有限責任曾令工業資本脫離人身債務；而家若 AI 可喺沙盒內當「可起訴主體」，人類成員卻大多躲喺盾牌後，受害者面對嘅將係日誌、資本門檻同解散程序，而唔係可對話嘅決策者。眾議院監督委員會主席 Comer 已就潛在傷害與透明度展開調查；學者警告責任外包同缺乏整體監管藍圖。文明寓言好冷酷：當法律主體可以係 agent，問責鏈就變成演算法黑箱加律師函。

少啲「美國法律傳統內治理 AI」口號。先問——若 agent 越權簽約、傷害第三方，盾牌保護嘅係創新，定係令權力更難被追究。把公司交畀演算法，唔係效率升級，係主體性讓渡。

Linus

開源：Talk is cheap——FlashProve 身份證明開源，部署仍然零

人物：Linus Torvalds · 擺 code／可驗證證明出嚟；封閉 API 背後偷換便宜模型＝行銷；有規格無部署就係嘴砲。

熱度 A

圖源／引述自 Samuel Boivin/NurPhoto／Getty／TechCrunch（外部連結）

Talk is cheap. Show me the goddamn code——同埋會真正上線嘅驗證，唔係另一份「開源規格」新聞稿。

Anthropic 公開 FlashProve：用可證明推論同模型指紋，令用戶可加密驗證輸出真係來自聲稱嘅模型，同時唔洩露權重；目標包括阻止實驗室偷偷換成更平模型、或用更貴模型刷榜，亦可核實第三方「已用前沿資安模型掃過庫」之類聲稱。規格同部分實作已放 GitHub 開源——跟住一句研究仍在進行，Anthropic 同其他實驗室「無計劃部署」。工程翻譯：嘴砲開源，部署零。

我維護過大型 codebase，最清楚呢種模式——放骨頭證明善意，真刀真槍嘅推理路徑繼續鎖喺封閉 API。指紋唔公開權重係合理工程取捨；但若驗證管線永遠停喺 blog post，用戶每日面對嘅仍然係「供應商話你用緊邊個模型」。鄰近一則更刺眼：DeepMind 用 AI agent 加速舊式 RSA-1024 相關密碼分析（簽名場景約一千六百倍量級），現代 2048 未受影響——重點係可重現研究，而唔係新聞稿分數。

少啲「邀請社群改進」演講。把可審計 harness、可對帳嘅生產驗證、同至少一條唔使求情嘅防衛路徑擺上枱。唔擺？就當承認封閉高牆仍然係行銷同遮笨拙。代碼透明先係技術自由；其餘全部係嘴砲。
