Swisher

審訊：骨相估齡全球上線——和解之後，掃描升級成公關

人物：Kara Swisher · 唔玩公關遊戲。最高約 180 億和解之後，Meta 把「保護青少年」譯成對全球檔案、留言同骨相的測齡機器。

熱度 A

圖源／引述自 Jonathan Raa/NurPhoto／Getty／TechCrunch（外部連結）

冇人問過你同唔同意被量骨相。Meta 把一場最高約一百八十億美元的和解，翻譯成對全球用戶檔案、留言同影像的大規模年齡推估，再包裝成家長安心。

TechCrunch 報道：Instagram 的 AI 測齡會分析整個檔案的語境線索，例如生日慶祝或年級，並掃描帖文、留言、簡介同說明；視覺線索包括身高或骨相。即使用戶填寫成人生日，系統仍可把懷疑未成年者送入 Teen Account：默認私密、只准已連結對象私訊、隱藏有害留言。Meta 官方網誌確認，該技術即日起全球擴展；Facebook 繼續推開，Threads 計劃今年稍後跟進。背景係八月與美國五十二個州檢察長達成協議，承諾加強識別十三歲以下兒童同十三至十七歲青少年。

呢套唔係慈善，係權力遊戲。平台先被控傷害青少年，再把「我們會更努力找出未成年」寫進和解履約，換取掃描範圍升級。澳洲已開始使用 Apple 的年齡區間訊號；Meta 進一步呼籲立法，要求 app store 向所有應用統一提供經驗證的年齡，並點名 TikTok 與 YouTube 跟做。公關句子係「即使填成人生日都放入保護」；權力翻譯係：你嘅自我陳述唔再算數，模型睇文、睇相、睇骨相先算數。圍牆花園自己定義邊個係小孩，再試圖把識別責任外判到作業系統層。

問清楚先。誰核准用骨相估齡？估錯成人會被鎖進青少年模式，定估錯青少年會被放行？訓練樣本從邊度來、存幾耐、同廣告系統有冇隔牆？和解書唔等於赦免狀。硅谷最老嘅把戲：先造成傷害，再把監控升級賣成補救。資金同訴訟風險下的道德表演，永遠講緊安全；被掃描嘅人很少被問過一句同意。

Linus

開源：Fable 5.2 吹爆黑洞同費馬——權重同證明擺上枱未？

人物：Linus Torvalds · Talk is cheap. 巨型科學聲稱對上 Mythos 驗證牆；官方 Office 技能仲被指可載入植入庫。

熱度 A

圖源／引述自 Cath Virginia／The Verge（外部連結）

Talk is cheap. 新聞稿可以喺一日內解決兩個開放物理問題、用一千個 agent 三十小時形式化費馬最後定理，再由空資料夾用八日砌出可開機作業系統。工程師只問：獨立的人重跑到未？

Anthropic 十一月九日發布 Claude Fable 5.2 與 Mythos 5.2，兩者係同一底層模型：Fable 加上網絡安全與生物學防護後對所有人開放；Mythos 只開放畀通過生命科學或網絡安全驗證計劃的機構。定價為每百萬輸入 token 八美元、輸出四十美元。基準表上，FrontierCode 2.0 在最高力度錄得約百分之四十九點一。公司又稱核心代碼庫逾九成已合併改動由 Claude（加人指導）寫成；黑洞物理據稱已有預印本，費馬形式化亦有專頁。有 PDF 好過只有投影片。

但我維護過大型 codebase，最憎把「我們自己跑出來的分數」當成物理定律。預印本要經得起對手復現；形式化要公開 Lean 庫等人 fork；「設計三部可運作電路」要交出原理圖同測試紀錄，唔係只放宣傳片。Mythos 繼續關在驗證牆後，外界無法審計同一套權重解除防護後做啲咩。更失修的是依賴項：AIR Security 指官方 Office 技能在 Linux 上從固定臨時路徑載入共享庫，植入檔案即可在處理文件時執行代碼。Dark Reading 報道 Anthropic 認為問題超出其安全邊界，因為跑在沙箱裡。官方技能都係軟件依賴；沙箱唔係免責金牌。

少啲 daunting technical challenges 海報。把可審計的權重、證明庫同可重現實驗擺上枱。唔擺？就當承認封閉高牆仍然係行銷，同埋遮住你唔想人 fork 的部份。代碼透明先係技術自由；其餘全部係嘴砲。

Thompson

戰略：Google 一年四套 TPU——要喺推理層拆 Nvidia 的聚合

人物：Ben Thompson · 稀缺層仍在加速器；Google 用系統模組化＋TorchTPU 搶推理與 agent 量產市場，而非再出一顆芯。

熱度 A

圖源／引述自 Google（外部連結）

戰略假說：加速器的稀缺層仍然係 Nvidia 用 CUDA 生態同出貨節奏聚合咗訓練需求；Google 的反擊唔係再出一顆「更快的芯」，而係用系統模組化，把硅、封裝、網絡同軟件相容層垂直整合，搶推理同 agent 量產市場。

Google 十一月九日由基建首長 Amin Vahdat 宣布第八代再加兩套系統：TPU 8tx 與 TPU 8i Max，令呢一代一年內共四套（四月已推 8t 訓練、8i 推理）。重點係系統唔等於新芯片：8tx 用同 8t 同一塊硅，搭配第五代 AMD EPYC，把機密運算做進硬體，令敏感數據同模型權重在運算中仍被隔離，面向政府同受監管企業，並稱延遲較 8t 可低至一半。8i Max 把兩顆 8i 封進同一封裝，運算、SRAM 與 HBM 頻寬倍增，瞄準跨代碼庫或數小時影片的超長上下文，同一機架可塞入雙倍硅。公司稱 TPU 業務已有近一百個外部客戶；未公布售價同確切供貨日。

價值鏈翻譯直白。Nvidia 握的唔只係晶片性能，而係開發者預設會寫 CUDA、買家預設會排隊買 GPU。Google 開源 TorchTPU，讓 PyTorch／Hugging Face 少改代碼上 TPU，再配 vLLM、SGLang 與 Cloud Pathways——目的係降低轉換成本，把需求從「買誰的卡」改寫成「喺誰的雲、誰的系統棧上跑」。感情零分：機密運算撬開合規預算；長上下文承接 agent 時代的記憶體牆。誰能把推理變成日常用量，誰就能稀釋 Nvidia 在訓練時期建立的議價權。

CUDA 生態同供應合約仍然厚。幾年後回望，今日這兩套系統只係條款修訂：價值會流向同時控制硅、機架、網絡同開發者入口的一方。聚合者理論只認一件事：需求在邊度被整合，供應端就喺邊度報到。

Snowden

監控：晶片版「Find My」——出口管制正在要求硅片報到

人物：Edward Snowden · 冇免費午餐。三項晶片法案更可能塞進國防授權法案；位置驗證一旦落地，算力就要打電話回家。

熱度 A

圖源／引述自 Cath Virginia／The Verge（外部連結）

冇免費午餐。華府要用出口管制卡住先進算力，就想令每顆高階加速器學會報位置——呢唔係比喻，而係正在被推進國防授權法案包裹的法律架構。

路透社十一月九日報道：黃仁勳承認與一名美方指稱為中國情報人員的女子有關係後，國會更傾向把三項晶片法案納入二零二七財年國防授權法管理包裹。其中包括《AI Overwatch Act》（讓國會更深介入先進晶片出口）、《Chip Security Act》（要求企業追蹤晶片以防走私）與《MATCH Act》（推動盟國收緊更多半導體設備對華出口）。眾議院外交事務委員會較早前已通過三案；Warren 與共和黨議員 Banks 發表聯合聲明，稱此事令國家安全疑慮「更加緊迫」。Nvidia 據報係前兩案的最大反對者。

CSET 與 IEEE Spectrum 拆解所謂「AI 晶片版 Find My」：以 ping 為基礎的位置驗證（PLV）量度芯片到可信伺服器的往返時間來估計位置；新芯片可做進硬體，存量或靠韌體更新。限制一目了然：離線或運輸中的芯片追唔到；停止回應時分唔清係轉移、關機定蓄意斷線；有資源者可偽造位置；最佳精度約二十英里；PLV 只知芯片在哪，唔知邊個在用。商務部還可獲權核實已出口產品的擁有權同位置；許可持有人若得悉轉移或篡改須迅速上報。

一旦架構落地，監視對象就唔再只係「運去某一國的那批貨」。任何被定義為覆蓋產品的加速器，都可能被要求對可信伺服器證明自己仲喺獲批座標。出口管制的語言係國家安全；工程翻譯係：算力開始擁有必須打電話回家的身分證。你用便利換來的，係對物理計算位置的持續可見性。當硅片都要向政府報到，監獄嘅牆就砌到機房裡。
