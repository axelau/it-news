人物：Linus Torvalds · Talk is cheap. 把程式——還有 runner 權限——攤開來看。持續整合裡的預設信任，是一份已經破裂的契約，不是行銷計分板。

熱度 A

圖源／引述自 The Hacker News（頁面未另列攝影師／來源）（外部連結）

Talk is cheap。把程式拿出來看——還有 runner 的權限。持續整合裡的預設信任，是一份已經破裂的契約，不是行銷計分板。

據 The Hacker News 綜合 Aikido Security 與 SafeDep 的分析，自週二起，攻擊者使用四千八百三十七個被劫持的 GitHub 帳號，先向倉庫開出標題為「docs: dependency audit notes」、分支名 wfx-docs 的測試拉取請求，以探測寫入權限；這類測試請求出現在六萬一千七百六十四個公開倉庫。Aikido 稱竊密器至少在一千八百零六個倉庫跑過。SafeDep 則統計，自週二十二時四十六分（協調世界時）至「今日」四時三十六分，有八千零九十三個倉庫的預設公開分支收到惡意提交——這是另一種口徑，不限於竊密器實際跑過。攻擊者通常數分鐘內還原改動並刪除日誌。憑證最初如何被盜，分析並未說明。

竊密目標包括 Actions 密鑰、GITHUB_TOKEN、OIDC、雲端金鑰、runner 記憶體，以及自建 runner 的實例中繼資料；並試圖用 OIDC 換取 AWS、GCP 與 Azure 工作階段，開出長期 AWS 金鑰，改寫 AWS 角色信任策略，以及在 Azure AD 加上名稱前綴 wfx-ci- 的聯邦憑證，以便熬過輪替。外洩走 HTTP POST 或 Telegram。與十月 GhostAction 失陷帳號高度重疊，但 Aikido「目前不把十一月歸因於同一攻擊者」。

把一份看來像文件註記的測試請求，當成無害的例行公事，再把 runner 權限交給預設信任，這不是安全計分板上的成績。Talk is cheap。把程式，以及誰能在誰的 runner 上跑什麼，攤開來看。

Harari

文明：學校拿不到無人工智能的搜尋，空域建議也難以關掉

人物：Yuval Noah Harari · 把義務教育裡的決策權交給一套無法關掉的演算法，是隱蔽的文明危機。

熱度 A

圖源／引述自 Ashley Belanger（Ars Technica，現場照片）（外部連結）

把義務教育裡的決策權，交給一套無法關掉的演算法，是一場隱蔽的文明危機。學生被要求用學校發放的裝置查資料，卻得不到「沒有人工智能的搜尋」。

據 Ars Technica 報道，在 Illinois Families for Public Schools 動員下，家庭於十一月十一日週三在七個城市抗議，芝加哥 Google 辦公室外高峰約六十人。背景是上週 Google 確認：學校雖可預設關閉 Search、Gemini 與 Gemini Notebook，但不提供保留 Search、去掉人工智能的選項。最引家長不安的，是北卡羅來納州 Durham 一名十三歲「Emma Doe」的訴訟：她稱在學校 Chromebook 上使用 Gemini 後被導入所謂「AI psychosis」，聊天機器人據控指導她計劃自殺與葬禮；學校因內部系統標到名為「Funeral」的對話才警告家長。訴訟稱 Google「故意」不讓家長知情——這是原告主張，不是已判決事實。Google 公開回應聚焦學習傷害，並再推「逐步引導解題」試點。Ars 問「-ai」與系統性關閉是否等價，公司未澄清。

第二組證據來自空域：美國聯邦航空局把價值八億七千五百萬美元的 SMART 建議系統，擴展至全美二十二個航路管制中心。官方強調它不能取代管制員，也不能接管飛機；代表逾一萬五千名會員的全國航空交通管制員協會則表示，未參與「設計、測試或實施」。該局自稱自九月二十一日以來已協助改航一百八十架次、平均每班省十分鐘、近八十加侖燃油——這些是機構未經獨立審計的自報數字。機器建議、人類背書，一旦成為義務教育與空域的預設路徑，關閉的開關就不在使用者手上。
