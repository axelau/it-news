Jobs

This is junk：Siri AI「全面開放」只係配額化粧嘅臃腫預覽

人物：Steve Jobs · 堆砌 App Intents、螢幕感知同 skills，卻用日額同地理把體驗砍成半成品——缺乏品味。

圖源／引述自 David Imel／The Verge（外部連結）

This is junk.

開放唔等於完成。Apple 把 Siri AI 開發者預覽灑向全部開發者：App Intents、自然語言、螢幕感知、skills 串連——參數表寫得像聖誕樹。同一頁細字寫住每日用量上限，歐盟 iOS 暫時缺席，App Store 提交要再等春季。這不是產品，是行銷部用功能清單填滿的空洞盒子。

缺乏品味從第一個決定開始。真正的助理應該消失在動作裡，而不是逼用戶記住配額、司法區同 beta 標記。你每加一層「能力」，就多一層要解釋的例外。美學不是圓角；美學是敢刪。今日這套預覽像把半成品廚房电器擺上櫥窗，再貼「即將支援全球」標籤——櫥窗在說未來，用戶摸到的是限制。

人性設計有一條鐵律：承諾必須小於能力，體驗必須大於簡報。Siri AI 反過來做。開發者被邀請進園，卻發現門鎖仍按地區與日額轉動。這摧毀的不是規格，是信任——用戶以為買到同一部電話，實際買到一份附帶條件的體驗許可證。把複雜藏進細則，再對外喊「全面開放」，正是最廉價的傲慢。

同周產業還在堆更多旋鈕：動畫 GIF、多 agent 工作區、無限簡報。堆砌解決不了空白。少堆功能。把配額拿掉，把地理分裂拿掉，把「再等數月」拿掉，先交出一個乾淨、完整、可預期的動作。否則這只是又一堆缺乏品味的臃腫垃圾。This is junk。

Swisher

別玩公關：Apple 削工程師 AI 日額，對外仍唱全力擁抱

人物：Kara Swisher · 追資金——對內配給、對外開閘、隔壁燒七位數挖洞併購；股價保衛戰先於員工 token。

圖源／引述自 STR/NurPhoto／Getty／TechCrunch（外部連結）

別跟我玩公關文字遊戲。追資金流向。

Bloomberg／TechCrunch／Verge：Apple 十月起把部分工程團隊每日 AI 開支上限由約三百美元削到兩百，並醞釀再砍到約一百；非工程傳低至約二十五美元一日。同週對外劇本係 Siri AI 向全部開發者開閘。同週產業另一面：OpenAI 燒約一百二十一万美元 API 工業化挖出九百四十八條 Linux 提權路徑；OpenAI 同 Meta 分別買下 Pierre 同 Conductor。一邊員工配給制，一邊股東簡報「全力擁抱」——呢個就係矽谷權力遊戲嘅經典分賬。

道德破產唔一定係犯法，而係對內儉、對外吹，仲要員工同開發者替股價敘事買單。CEO 唔會因為模型突然變差而砍 token；係因為 CFO 贏咗董事會，單位經濟壓過幻燈片。你問點解公司肯花七位數搵 root、肯買 Git 舖，唔肯加你日額？因為你嗰幾百蚊係費用中心，佢嗰筆係「論文＋產品＋監管敘事」三合一 CapEx。

連續追問好短：邊個簽署削額？削額有冇寫入對外 AI 路線圖？開發者預覽開閘同內部配額縮水，邊個先服務股價？隱私同安全公關最愛講「負責任」，負責到員工 Slack 彈 quota exceeded 為止。

別再吞「轉型」簡報。打開帳本。股價保衛戰用員工 token 同用戶配額作燃料時，就唔好裝成文明進步。

Thompson

聚合者拆 forge：Pierre×Pando 之後，人類 PR 護城河已死

人物：Ben Thompson · 稀缺層轉去 agent 可讀源碼圖；誰控儲存／diff／並行工作區，誰抽乾舊源控生態。

圖源／引述自 Meta／TechCrunch（外部連結）

戰略假說：軟件價值鏈嘅稀缺層，正由「誰託管人類 PR」轉去「誰擁有 agent 可讀嘅源碼圖」。

OpenAI 收購 Pierre、把 Code Storage 收進 Codex，同周披露內部 Pando（號稱每日近 PB 級 Git 流量）；Meta 收購多 agent 工作區新創 Conductor，雲服務限期關停。呢唔係兩則人情味併購新聞，而係聚合者對舊 forge 生態嘅降維打擊。GitHub 優化人類 review、issue、社交證明；agent 並行寫碼之後，瓶頸移到儲存吞吐、diff 速度、隔離工作區同合併編排。誰控制呢層介面，誰就聚合開發者需求，並逐步抽乾以人為中心嘅舊商業模式護城河。

市場生態演化好血腥，亦好冷靜。被收購產品嘅雲用戶變成遷出問題而非客戶——Conductor 十一月關服刪資料，就係價值鏈轉移時常見嘅屍塊。開源 Diffs／Trees「繼續開源」係表層兼容；表層之下，agent 工作流被鎖進 Codex／Muse 封閉編排。聚合理論講過無數次：控制需求端體驗嘅人，最終定義供應端死活。傳統源控公司若仍以為護城河係「最多 human star」，已經喺錯誤抽象層防守。

舊模式唔會禮貌死亡。佢會喺每次 agent push、每次自動 merge、每次「你嘅 repo 其實住喺我哋儲存層」入面，被靜靜拆骨。感情零分；只餘結構。

Vestager

看門人開閘？Siri AI「全面開放」惟歐盟 iOS 缺席

人物：Margrethe Vestager · 以創新為名按司法區開關園門＝市場封鎖；配額、時間表、地理三把匙仍在 Cupertino。

圖源／引述自 David Imel／The Verge（外部連結）

以「創新」為名、按司法管轄區開關園門，本質上係看門人行為，必須受競爭法審視。

Apple 向全部開發者開放 Siri AI 預覽：App Intents、自然語言、螢幕感知、skills 組合；App Store 提交約春季。同一份說明寫住——歐盟 iOS 暫未提供，並設每日用量上限。圍牆花園可以裝成廣場，但門鎖仍喺 Cupertino 手中：時間表、配額、地理，三把匙。

公平競爭立場好簡單。裝置預設助理若係平台入口，就係市場看門人。對第三方「開放」卻把整個執行 DMA 嘅區域剔走，唔係技術腳註，而係用產品設計做市場封鎖。消費者權益亦唔係口號：用戶以為自己買到同一部電話、同一套 Siri，實際能力因地緣監管對抗而被降級——呢種分裂本身就係剝削選擇權。

封閉生態慣用三步：先話安全同品質，再話區域未就緒，最後用配額同審批把第三方變成佃農。今日劇本無新意，只係 AI 標籤換皮。數據同入口控制若繼續捆綁銷售敘事，監管就唔能把「開發者預覽」當成豁免金牌。任何以創新包裝掠奪競爭、剝削用戶數據與入口控制嘅行為，都應當面對制裁與必要時嘅拆解——唔係等公關講完「再等數月」。

警告寫喺門口：看門人冇權自行定義邊個市場先有權享受「開放」。法規先至係門；花園牆唔係。

Miller

別吹雲端：德州機房踩剎，先撞上電網同水，唔係演算法

人物：Chris Miller · AI 競爭本質係瓦特、水權、變壓器同地緣政治；選票改寫超大規模算力地圖。

圖源／引述自 Getty／MIT Technology Review（外部連結）

實體死穴寫在電錶上：沒有瓦特，就沒有權重。

德州原是美國 AI 資料中心增長最快的戰場。選後民主黨路線勝出聯邦參院、新州長陣營傾向暫停或收緊機房許可，並把水電與社區否決權推回桌面。MIT Technology Review 與 The Verge 同周把這條線講清楚——「電力政治」不再是評論員修辭，而是工業許可證。你儘管紙上談兵吹雲端與模型規模；現場決定勝負的是變壓器交期、冷卻水源、輸電線路與地方稅優。

半導體史重複同一課。光刻機、先進封裝、高壓電網——每一層都是國家工業戰略的實體關卡。把算力競爭簡化成「誰有更好的軟體敘事」，等於嘲笑晶圓廠門崗。出口管制卡住的是設備與材料；地方選票卡住的是機房能不能接上電網。兩者同屬物理世界對幻燈片的否決權。誰掌控產能地理，誰就定義下一輪 AI 軍備的真實上限。

工業戰略比喻很直白：帝國先搶煤與港口，才談艦隊。今日的艦隊是 GPU 叢集，港口是變電站。德州踩剎，不是「反科技情緒」可以公關化解的軟問題，而是產能地理被政治重劃。軟體派若繼續輕視硬體與基建，終會發現自己的 AGI 簡報停在缺電的工地門口。

別再只數參數。先數兆瓦、英畝水權、同邊張選票握著開工章。實體製造與地緣政治，才是這場戰爭的正文。

Linus

Talk is cheap：Pierre／Conductor 收編，封閉 agent 棧先鎖碼再嘴砲

人物：Linus Torvalds · 開源放骨頭、閉源吃肉——Code Storage 入 Codex、Conductor 關雲刪資料，就係高牆綁架用戶遮笨拙。

圖源／引述自 OpenAI（外部連結）

Talk is cheap. Show me the goddamn code.

今日呢套戲好熟：OpenAI 宣佈收購 Pierre，把 Code Storage 收進 Codex；Meta 收購 Conductor，再通知雲端用戶十一月十三日改唯讀、二十日關服刪資料。公關稿寫「agent 原生源控」「多 agent 並行工作區」。工程翻譯只有一句——起高牆，把 Git 圖鎖進自家產品，再叫呢道鎖做平台。

我維護 kernel 幾十年，最憎兩種人：一種嘴砲創新唔肯開碼；一種開源放骨頭、閉源吃肉。Pierre 話 Diffs／Trees 繼續開源，好。肉喺邊？喺交割後入 Codex 嘅 Code Storage，同埋 Conductor 轉入 Meta Muse 編排棧嗰條路。開源 library 係門面；真正決定你可唔可以 audit、fork、自己 host 嘅儲存同編排，就靜靜收入圍牆。Talk is cheap 到呢度已經變：Talk is a press release.

每一個封閉 coding agent，如果唔肯公開編排同儲存路徑，就係叫你靠祈禱 debug。雲兩星期後死、本地版二零二七年初停更——呢啲唔係夥伴關係，係搶地加新聞稿。維護過大型 codebase 嘅人都知：最崩潰唔係 bug 本身，而係你連「邊度改、點樣 merge、誰批準」都睇唔到，只能等供應商心情。

少啲嘴砲「為開發者」。把可重現嘅管線、可自託管嘅圖、同埋遷出工具擺上枱。唔擺？就當承認封閉高牆係為咗遮笨拙同鎖客。代碼透明先係技術自由；其餘全部係行銷。

Snowden

冇免費午餐：DreamHost 月級失竊＋Postman 靜默 AI 插件

人物：Edward Snowden · 便利工具背後係憑證、session 同預設信任鏈被系統性收割；數位主權一早抵押。

圖源／引述自 Thomas Fuller/SOPA／LightRocket／Getty／TechCrunch（外部連結）

世上沒有免費的午餐。你交給託管商的信箱，本來就是監視的入口。

DreamHost 向加州通報：攻擊自八月起，經檔案管理器漏洞取得 session token，竊取客戶電郵與憑證；偵測滯後到近周停電與重設密碼後才披露。受影響「遠低於一成」——公關最愛用分數麻醉你。同一光譜上，開發者社群續炒 Postman Desktop 自動加入 Claude Code／Codex 類插件並嘗試信任 startup hook。兩個故事同一機制：你為了「省事」交出持續登入與預設執行權，攻擊面就寫進日常工作流。

隱私陷阱從不先喊「監控」。它先喊方便。檔案管理器要你長駐 session；API 客戶端要你一鍵信任 hook；智慧家居助理要你把安防場景交給雲端模型。每一層便利，都是把鑰匙掛在走廊。機構——無論是雲託管商還是工具大廠——一旦出事，披露節奏永遠服務法律與股價，而不是你的收件匣。

數位監視監獄的牆，是用「預設開啟」砌成的。你以為自己只是寄信、測 API；系統看見的是可重放的身份與可橫移的信任鏈。權力從不對等：你無法審計對方幾個月前的日誌，對方卻能在你不知情時延長 token。

別再為免費或「好用」交出默認信任。顯式 opt-in、最短 session、可驗證遷出——否則便利就是對個人數據與數位主權的無死角收割。

Harari

把守門權交給演算法：948 條 root 路徑之後的文明轉折

人物：Yuval Noah Harari · 人類正把漏洞發現與攻防決策工業化讓渡給 AI 管線——這是隱蔽的主體性交出。

圖源／引述自 OpenAI（外部連結）

歷史反覆警告：當一個文明把守門權外包給自己無法理解的系統，崩解往往先於警報。

OpenAI 公開自主漏洞管線：一次跑出兩千三百零八個候選、重現一千七百二十四、得到九百四十八個可工作 Linux 本地提權，API 成本約一百二十一點三万美元。公司把它寫成「少咗千條通往 root 的路」。在文明尺度上，這更像另一件事——發現、利用、分診的節奏，開始由演算法管線而非人類工匠社群主導。人仍按按鈕、仍報送維護者；但篩選什麼值得成為「威脅」的注意力，已大規模轉移。

農業時代把體力外包給牲畜；工業時代把重複動作外包給機器；此刻我們把「判斷什麼危險」外包給模型集群。Deepfake 搶奪感官真實；自動化挖洞管線搶奪安全真實。兩者同屬一場隱蔽危機：精英機構擁有管線，普通人只收到補丁說明書。你以為自己仍在決策；你只是在消費系統輸出的優先級。

社會寓言很古老：把鑰匙交給會自己配鑰匙的管家。管家越能幹，主人越不必懂鎖。直到有一天，整座城的門衛邏輯只活在外人無法審計的權重裡。短期商業利害——每條利用約一千二百七十九美元——遮不住長期問題：誰定義「已足夠安全」，誰就定義集體恐懼的節奏。

別把工業化挖洞只讀成資安新聞。它是人類把心智與守門決策權讓渡給演算法的又一里程碑。主體性一旦交出，很少會按公關時間表回來。

Register

又嚟：Meta 收 Conductor，兩星期後雲端關燈刪庫——工程師收屍

人物：The Register · 半成品併購硬吹「多 agent 未來」，前線用戶為 KPI 遷出窗口買單。

圖源／引述自 Meta／TechCrunch（外部連結）

恭喜各位：又一份「改變開發者工作方式」嘅新聞稿，附送自備紙箱同淚水。

Meta 收購多 agent 編程新創 Conductor——金額？保密到好似國家機密。時間表倒係好慷慨：十一月十三日雲端改唯讀，二十日關服並刪資料；本地版「維護」到二零二七年初。翻譯成人話：我哋買咗你嘅玩具，今日起叫你搬家，唔搬就燒屋。公關當然寫「併入 Muse 編排棧」「多 agent 並行工作區」。前線工程師收到嘅係 countdown timer 同「請自行匯出」。

呢種戲碼，Register 讀者睇到眼冤。大廠最愛把半熟新創當戰利品掛喺幻燈片，再叫付費用戶為整合 KPI 做免費 QA。上次係改名、強制更新、退休你依賴嘅 API；今次係直接刪庫。荒謬 IT 災難比喻？好似消防局收購街坊滅火筒舖，宣佈下月回收所有筒，請市民改用集團全新「智慧水帶生態系統」。

諷刺綽號可以叫 Conductor 做「Disconductor」：指揮大家離場。OpenAI 同日收 Pierre、把儲存鎖進 Codex——軍備賽好熱鬧；被踩扁嘅永遠係細戶 repo 同值班 SRE。半成品硬吹突破，全球第一線工程師就為無能同季度目標買單。

記住呢條：凡新聞稿出現「seamless migration」，請即開備份。seamless 通常解作「你自己 seamless」。

Musk

第一性原理：AI 機房共識係屁話——冇電冇水就冇估值

人物：Elon Musk · 業界「繼續起算力」敘事撞上電網、水權同選票；物理限制唔睇你嘅融資輪。

圖源／引述自 Getty／MIT Technology Review（外部連結）

業界共識同公關全是屁話。先算焦耳，再吹估值。

德州剛被捧成美國 AI 資料中心新震央，選後政治立刻把許可、稅優、水電推回剎車。超大規模雲端嘅簡報仍然寫「GW 級校園」「數十萬 GPU」。第一性原理好殘忍：輸出智能之前，你要先有穩定電力、散熱水、變壓器同肯簽字嘅地方政府。呢四樣缺一，你嘅模型權重就係貴價磚。物理唔讀 PitchBook。

商業邏輯同樣血腥。CapEx 可以靠敘事膨脹；電費同水權訴訟唔會。你見過幾多「AI 無限需求」投影，係假設電價同社區同意永遠順住？德州呢一腳，係市場用選票對泡沫做壓力測試。邊啲項目靠補貼同寬鬆許可堆起來，邊啲就會喺真實成本曲線上裸泳。融資輪可以延期；電網尖峰唔會為你嘅 ARR 讓路。

俯瞰視角只有一句：你哋好多人口裡嘅「算力護城河」，其實係「暫時仲借到電」。一旦電網同政治同時收緊，所謂落地就變成工地圍板。OpenAI 可以花約一百二十一萬美元工業挖洞做防護敘事；挖唔到下一座變電站。泡沫唔係股票圖上嘅曲線，而係假設物理約束會自己讓路。

別再背誦共識。拿計算器：兆瓦、升水、融資成本、同開工許可。算唔到利潤，就唔好裝成文明躍遷。底層工程先決；其餘全部係噪音。唔識電網同熱力學，就唔好同我講 AGI 時間表。
