Thompson

戰略：要挑戰星鏈，卻把發射權買在還沒飛穩的別人火箭上

人物：Ben Thompson · 星座競爭的死穴不是衛星軟體，是誰握著可反覆使用的發射產能。

熱度 A

圖源／引述自 Manuel Mazzanti／NurPhoto via Getty Images（The Verge）（外部連結）

星座競爭的死穴不是衛星上的軟體，是誰握著能反覆把硬件送上天的發射產能。沒有垂直整合的發射能力，所謂挑戰星鏈，只是一張向對手與尚未穩飛的供應商購買運力的訂單簿。

據 The Verge 與 Ars Technica，聯合發射聯盟（ULA）的火神號（Vulcan）於東部時間十一月十五日中午十二時四十分，從佛羅里達州卡納維拉爾角太空軍基地四十一號發射台升空，載四十顆亞馬遜 Leo 寬頻衛星，香港時間為十六日凌晨一時四十分。ULA 其後在 X 聲明：發射主任收到的數據確認，飛行約十分鐘出現異常，「未能把亞馬遜任務送入軌道」。公司稱當時沒有足夠數據解釋原因，將調查後「盡快」復飛。Ars 寫這是 ULA 自二零零六年由波音與洛克希德馬丁火箭部門合併以來首次完全任務失敗；The Verge 用「據報」。原因仍在調查，不能寫死。Ars 多名消息源稱異常在助推級，而非上面級 Centaur V 或固體助推器，並描述藍色起源所製 BE-4 主引擎似比預定時間至少多燃燒三十秒；Spaceflight Now 則寫問題出在 Centaur 點火期間。已打開的 ULA 聲明只說飛行十分鐘異常，兩種技術表述互相衝突，本報不把任何一方當成已證實的故障位置。

真正改寫市場結構的，不是少了四十顆衛星，而是發射這項稀缺互補資產被進一步鎖死。Ars 寫：周日是亞馬遜向 ULA 預訂三十八次 Vulcan 飛行的第一次，每次計劃送四十顆或更多 Leo；星座目前三百九十六顆，第一代規劃三千二百九十二顆。公司十月曾稱已有足夠衛星可在年底前開始初始商用，但要滿容量仍需更多發射；最近宣布造出第一千顆，意味過半節點仍在地面。亞馬遜另向 Arianespace 預訂共二十四次，已飛三次；藍色起源 New Glenn 五月地面測試爆炸，發射台至少停到今年底。若此次被認定與 BE-4 有關，Ars 寫可能再拖 New Glenn 復飛——這是條件句，不是結論。「無限期停飛」是 Ars 的預期，不是 ULA 用語。亞馬遜還向直接對手 SpaceX 預訂獵鷹九號：Ars 寫還剩十次，Spaceflight Now 寫共十三次，口徑不同，不可合併。發射垂直整合的一方，在商業星座與國安發射上都更難被取代。價值鏈已經投票：誰能穩定發射，誰就決定星座能不能追上。

Jobs

品味：一副沒有畫面、走不開 iPhone、成敗全押在 Siri 的眼鏡

人物：Steve Jobs · 這不是一台新電腦，是一副要等明年、還可能再延期的配件。

熱度 A

圖源／引述自 Amelia Holowaty Krales／The Verge（圖為 Meta 第二代 Ray-Ban，僅供厚薄比較，不是 Apple N50）（外部連結）

一副沒有畫面的眼鏡，不是新的個人電腦，是一副走不開手機、成敗全押在重建中 Siri 的配件。把「稍薄」寫成設計突破，是缺乏品味。

這不是蘋果官方發表。據 Bloomberg 的 Mark Gurman，經 The Verge 與 MacRumors 交叉：內部代號 N50 的第一款智慧眼鏡，擬於二零二七年六月全球開發者大會公布，同年年底前出貨，不會在會上即時開賣。第一款沒有擴增實境顯示。原型跑精簡版 visionOS，處理器改自較舊的 Apple Watch 芯片。外形據報比 Meta 第二代 Ray-Ban「稍薄」。充電是扁平、約 Tic Tac 大小的磁吸頭，MacRumors 寫三針接在左鏡腳末端，Gurman 說尚不確定量產是否採用這套充電。Wi-Fi 讓部分非第三方應用功能在 iPhone 不在身邊時仍可用，例如繼續聽音訊，但「不會作為完全獨立的裝置運作」。目前規劃需要新款 iPhone，不支援 Android；開發者不必另做眼鏡應用，軟體跑在配對的手機上。互動走 Siri：辨認建築、看冰箱建議餐點、翻譯、通話與通知。本月 iOS 27.3 首個測試版已加入更細的 Siri 控應用能力，自有應用支援計劃十二月，第三方二零二七年。員工據報把音訊說成「業界領先」；在一副還不能離機辦妥第三方應用的眼鏡上，音質再好，也只是把手機的聲音搬到鏡腳。

This is junk 的理由不在厚度，而在人與機器之間只剩下一張還沒就緒的嘴。沒有畫面，等於把整個體驗交給語音助手；助手若遲到，眼鏡就只是一副戴著充電的耳機。MacRumors 轉述 Gurman：硬體大致定案，剩餘障礙是軟體與人工智能，「進度落後，可能拖慢原定二零二七年上市」。相機版 AirPods 仍計劃同年下旬。一間以極簡界面起家的公司，現在把未來入口做成必須綁定手機、還可能再等一年的配件。品味不是把架子做薄，是讓人戴上之後不必先問：Siri，你準備好了沒有。

Torvalds

開源：刪掉 GitHub 倉庫，擋不住已經在公網跑的一千六百個控制台

人物：Linus Torvalds · Talk is cheap。寫「授權測試」不算負責；刪庫之後 fork 還在，才是維護失敗。

熱度 A

圖源／引述自 The Record／Recorded Future News（FBI 相關檔案圖，不是 ARTEX 控制台或界面）（外部連結）

Talk is cheap。在說明檔寫「只供授權測試」，然後在濫用報道後把 GitHub 倉庫刪掉，這不叫維護，這叫把已經擴散的代碼庫假裝收回。Fork、存檔和商業版還在跑，公網控制台還開著，刪庫只是把問題從自己的命名空間搬走。

據聯邦調查局十一月十三日 FLASH-20261113-001，開源、由大語言模型驅動的自主滲透測試框架 ARTEX，自至少二零二六年八月起被威脅行為者用來自動化從偵察到竊取的多個階段。框架本身不含自有模型，而是接外部模型，公告列出 Anthropic Claude、OpenAI GPT，以及 DeepSeek、GLM、Grok、Kimi 等。FBI 稱部分入侵可在三小時內從初始鎖定走到特權訪問，並降低技術門檻。開發者化名 Autumn-27，二零二六年七月在 GitHub 發布，約十週內獲估一千五百至二千個星標；在濫用報道後於十月八日下架。框架仍經社群 fork、本地化改版、存檔複本與商業版 ARTEX PRO 流傳。截至十一月初，研究人員識別逾一千六百個公網暴露的控制台，防火牆後部署可能更多。BleepingComputer 十一月十五日整理了這份公告。本報只寫高層事實，不寫利用步驟或重現方法。

已報告後果必須分源。FBI 提到南韓金融機構個資外洩，約六萬七千人；以及 ConnectWise Cloud Backup 供應鏈事件，使攻擊者得以對逾二千二百五十個下游租戶嘗試訪問（FBI 引 Microsoft）。BleepingComputer 稱 Microsoft 將該戰役歸於 Storm-0940；Huntress 當時識別至少一百六十二個被入侵租戶——這是經該媒體轉述，不可把二千二百五十寫成已被攻破的租戶數。亞馬遜威脅情報十一月十三日寫，誘捕網觀察到帶戰役記憶的代理請求，但「未能獨立核實代理自己聲稱的結果」。開發者可以刪掉自己的倉庫。他刪不掉已經在別人機器上跑的進程，也刪不掉一千六百個暴露在公網的控制台。那才是這次維護事故的核心：不是開源有罪，是把「授權」寫在說明裡、卻對擴散後的營運現實撒手。

Vestager

壟斷：撤銷罰單的理由如果是「合約沒逐份數完年期」，看門人就贏了舉證戰

人物：Margrethe Vestager · 排他條款的殺傷力在整片合約網，不在法官能不能點完每一份續約。

熱度 A

圖源／引述自 AP Photo／Richard Drew（Courthouse News Service：Google 標誌，紐約，2023-09-11）（外部連結）

看門人的排他條款，殺傷力在整片合約網，不在執法者能不能把每一份續約的年期點完。若撤銷近十五億歐元罰單的理由，是「存續期間沒有逐份細審」，競爭法就被抬到了看門人喜歡的舉證高度。

這不是本週的終局判決，也不是昨日意大利罰 Meta 那條隱私案。歐盟法院法務官 Juliane Kokott 於十一月十二日在盧森堡就 C-826/24 P（執委會訴 Google 與 Alphabet，Google AdSense）發表意見。據法院新聞稿 164/26：執委會二零一九年三月認定，二零零六年至二零一六年，AdSense for Search 合約中的排他條款、版位條款與事先批准條款違反歐盟運作條約第 102 條，罰款近十五億歐元。範本自二零零九年三月起，限制或禁止網站營運商展示競爭對手的搜尋廣告；版位條款要求保留 Google 廣告的顯著位置；更改展示前須事先取得批准。普通法院二零二四年九月十八日以未充分審查相關情形、尤其合約存續期間為由，撤銷該決定。執委會其後上訴。

Kokott 認為，普通法院把 Intel 判決下對「期間」這一標準的審查，抬到「每一項標準都可以單獨因為不夠細而整案撤銷」，屬要求過高。執委會對構成排斥效果的合約做整體評估，部分使用平均值，即已滿足義務；不必逐份解剖每一份合約及其適用，才能證明條款共同產生或可能產生排斥效果。她建議撤銷普通法院判決並發回重審。必須寫清：法務官意見對法院無約束力，法官仍在評議，宣判日未定。因二零一六年排斥效果舉證不足的認定未被執委會上訴，已確定，發回後罰款「無論如何」應下調。罰單沒有因為這份意見自動恢復。看門人用合約把競爭對手從搜尋廣告的版位上擠走；若法律只追究每一份續約夠不夠短，圍牆花園就會繼續以「可終止」為名，把排他寫進整片網絡。
